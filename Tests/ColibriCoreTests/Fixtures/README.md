# Test fixtures

Golden data for ColibriCoreTests, copied into the test bundle (`Bundle.module`).
Owned by the oracle harness (workstream F); other workstreams add files only in their
own subdirectory:

| directory | owner | contents |
|---|---|---|
| `oracle/` | F | upstream engine outputs for Qwen3-0.6B (`qwen3-0.6b-q8_0.json`) and the synthetic models (`tiny/<case>.json`): prompt ids, greedy ids (float reference and int8 path), per-step top logits, prefill logits. Written by `scripts/oracle/record.py`; format in `scripts/oracle/README.md`. |
| `quant/` | A | random blocks and their upstream C dequantisation |
| `tokenizer/` | B | prompt texts and upstream token ids |

No GGUF files here (`*.gguf` is git-ignored): synthetic models are regenerated by
`TinyModel` at test time (each `oracle/tiny` fixture records the model's fingerprint), and
the real model is read from `~/colibri-models/`.
